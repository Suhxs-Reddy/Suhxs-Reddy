## Featured Projects

### 🚦 [CATI — Context-Aware Traffic Intelligence](https://github.com/Suhxs-Reddy/sg-smart-city-analytics)

A novel YOLOv11 detector that adapts to environmental context (weather, time, camera ID, PM2.5) using **FiLM layers** — applied to Singapore's 90 live LTA traffic cameras. ~1.4% parameter overhead over vanilla YOLO, with per-camera learned embeddings.

> First published traffic detector to modulate detection features on real-time environmental metadata.

`PyTorch` · `YOLOv11` · `FiLM` · `BoT-SORT` · `data.gov.sg APIs` · `Docker` · `HuggingFace Spaces`

<br/>

### ⚡ [COLLIDE — AI Site Selection for BTM Data Centers](https://github.com/Suhxs-Reddy/EnergyHackathon)

End-to-end siting platform that scores hyperscale data center candidates across **land viability, gas reliability, and power economics** in seconds. Random Forests + GPU Gaussian KDE + GMM regime classifier + TOPSIS composite, with a LangGraph agent that answers what-if questions over live ERCOT/CAISO market data.

> Built for ASU Energy Hackathon 2026. Collapses a multi-month siting study into seconds.

`FastAPI` · `LangGraph` · `Claude` · `DuckDB` · `Leaflet` · `SHAP` · `Monte Carlo NPV`
